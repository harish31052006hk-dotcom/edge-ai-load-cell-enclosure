# Milestone 2: Detection and Evaluation

Milestone 2 evaluates detection performance, multi-class discrimination, anti-double-counting logic, real-time edge streaming, and metrological calibration checks.

---

## 1. M2 Objectives & Deliverables

1. **Simultaneous Multi-Class Detection**:
   - Accurately identify and separate `bottom`, `top`, and `enclosure_assembled`.
2. **False Positive & Sub-Part Suppression**:
   - Prevent assembled enclosures from being falsely double-counted as individual loose parts.
3. **Accuracy Verification**:
   - Test detection confidence scores across all physical test scenes.
4. **Metrological Calibration & Verification**:
   - Independent verification using known $32\text{ mm} \times 32\text{ mm}$ physical geometry.
5. **Edge Deployment Readiness**:
   - Document latency trade-offs and future Raspberry Pi 5 optimization pathways.

## 4. Metrological Calibration Analysis (`config/calibration.json`)

- **Calibration Standard:** Top Cover ($32.0\text{ mm}$ nominal).
  - Measured: Horizontal $= 131.0\text{ px}$ ($4.0938\text{ px/mm}$), Vertical $= 34.0\text{ px}$ ($1.0625\text{ px/mm}$).
- **Validation Sample:** Bottom Base ($32.0\text{ mm}$ nominal).
  - Measured Width: $33.47\text{ mm}$ ($\Delta = +1.47\text{ mm}$).
  - Measured Height: $49.88\text{ mm}$ ($\Delta = +17.88\text{ mm}$).
  - Result: `VALIDATION_FAILED` (attributed to non-perpendicular camera tilt).
- **Takeaway:** For high accuracy, camera must be mounted strictly normal (perpendicular) to the plane using the fixed overhead stand.
